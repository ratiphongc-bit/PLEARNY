# PLEARNY

PLEARNY is a Thai-language math learning adventure prototype for primary-school students. It combines short lessons and quests with a fantasy exploration interface.

## Demo

[Open the live demo](https://plearny-l37tbtr8.manus.space)

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. To verify a production build, run:

```bash
npm run lint
npm run build
```

## Stack

- Next.js 16 and React 19
- TypeScript and Tailwind CSS 4
- Three.js / React Three Fiber for 3D scenes
- Framer Motion for UI animation
